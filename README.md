# RADAR · 공시의 작은 변화까지

React + TypeScript + Vite + Tailwind CSS로 만든 공시 변화 모니터링 데모입니다. 연노랑과 차콜 테마, 자체 레이더 심벌, PC 사이드바와 모바일 하단 메뉴를 제공합니다. KB를 연상시키는 색감 요청을 반영한 독립적인 시제품이며 금융기관의 공식 앱이 아닙니다.

## VS Code에서 실행

Node.js 22.12 이상(현재 검증 환경: Node.js 26)이 필요합니다.

1. VS Code에서 이 저장소의 `KDA1` 폴더를 엽니다.
2. 터미널에서 아래 명령을 실행합니다.

```powershell
npm install
npm run dev
```

PowerShell에서 npm 실행 정책 오류가 나면 `npm.cmd install`, `npm.cmd run dev`를 사용하세요.

브라우저에서 **http://127.0.0.1:5173/** 을 엽니다. 개발 서버는 켜두어야 합니다. 포트 사용 중 오류가 나오면 기존 서버 터미널에서 Ctrl+C로 종료한 뒤 다시 실행하세요. 주소 뒤에 `**`를 붙이지 마세요.

이전 명령 `node server.mjs`도 Vite 개발 서버로 연결됩니다. 첫 실행에는 `npm install`이 필요합니다.

## 프로젝트 구조

```text
KDA1/
├─ public/logo.svg          # 레이더 심벌과 파비콘
├─ src/
│  ├─ components/ui.tsx     # 로고, 카드, 수치 비교, 모달, 종목 검색
│  ├─ lib/data.ts           # 타입과 가상 데이터
│  ├─ lib/store.tsx         # 공유 상태, 브라우저 저장, 이동 보호
│  ├─ screens/              # 피드, 종목, 상세, 알림, 설정
│  ├─ App.tsx               # 반응형 앱 셸과 메뉴
│  ├─ index.tsx             # React 진입점
│  └─ tailwind.css          # Tailwind v4와 테마 스타일
├─ tests/                  # 사용자 동작 중심 자동 검사
├─ design/                 # 제공된 PNG 14개 (원본 유지)
├─ index.html
├─ package.json
├─ package-lock.json
├─ tsconfig.json
├─ vite.config.ts
└─ server.mjs               # 이전 실행 명령 호환
```

Tailwind v4의 Vite 플러그인과 CSS `@theme`을 사용하므로 별도 `tailwind.config.js`, `postcss.config.js`는 필요하지 않습니다. `node_modules/`와 `dist/`는 Git에 올리지 않습니다. 저장소를 내려받으면 `npm install`로 의존성을 설치합니다.

## 구현 기능

- 변화 피드: 전체·내 종목·저장함, 공시 검색, 보고서·접수 유형 필터, 최신순·변동률순 정렬, 데모 새로고침과 로딩 표시
- 관심종목: 기업명·가상 코드·업종 검색, 추가·삭제, 삭제 취소, 온보딩
- 공시 상세: 공시별로 일치하는 수치 비교, 증감 바, 신규 문서 비교 불가 안내, 요약 복사, 북마크
- AI 근거: 사실과 예시 해석 분리, 원문 예시 펼치기, 확인 체크리스트, 정정 타임라인
- 알림: 개별 읽음·모두 읽기, 안 읽은 알림 필터, 미확인 배지
- 설정: 개별 토글, 발송 방식, 방해금지 시간, 보고서·종목별 설정, 변경 표시, 저장·되돌리기, 이동 시 미저장 확인
- 예외 상태: 화면 하단 ‘데모 상태’에서 5개 상황 확인
- 접근성: 버튼 이름, 선택 상태, 키보드 포커스, 네이티브 대화상자, 줄어든 움직임 설정 대응

관심종목·저장한 공시·읽음 상태·체크리스트·저장한 설정은 현재 브라우저의 localStorage에 보관합니다. 기존 버전의 관심종목과 설정 키를 재사용하고 값 형식을 검사합니다. 기기 간 동기화는 없습니다.

## 데이터와 디자인 범위

기업과 수치, 날짜, 공시 문단과 AI 해석은 **가상 예시**입니다. 실제 DART 수집, AI 생성 API, OS 푸시, 서버 저장은 연결되지 않았습니다. DART 링크는 특정 가상 접수 원문 대신 DART 홈페이지를 엽니다. 투자 판단용 서비스가 아닙니다.

제공된 PNG 14개를 기능 기준으로 유지하고, 사용자 요청에 따라 연노랑 테마와 PC/모바일 UI로 재설계했습니다. Figma 원본 URL이 없어 레이어를 직접 변환한 결과는 아닙니다. 로고와 UI는 SVG/CSS/React 요소로 표시하며 전체 화면 PNG를 앱 배경으로 사용하지 않습니다.

## 검증과 빌드

```powershell
npm test
npm run build
npm run preview
```

2026-10-30: TypeScript 검사·프로덕션 빌드, 16개 자동 검사를 통과했습니다. 검색과 보고서 필터, 북마크, 종목 추가·삭제·복원, 선택한 공시의 상세·AI·타임라인 일치, 신규 문서 처리, 설정 저장·미저장 확인, 알림 읽음, 손상된 저장 데이터 복구, 온보딩과 예외 5종을 검사합니다.

Vite 개발 서버의 HTTP 200 응답과 React 진입 파일을 확인했습니다. 사용자의 포인터 문제를 피하기 위해 Windows 원격 조작은 하지 않았으며 실제 브라우저 스크린샷을 통한 시각 검증은 미완료입니다.

`npm run build`의 결과물은 `dist/`이며 정적 호스팅에 배포할 수 있습니다. 이번 작업 범위는 로컬 앱과 GitHub 소스입니다.

## 모션 업데이트

- 화면 이동 시 부드러운 페이드·상승 전환, 카드 순차 등장
- 요약 통계와 비교 수치의 1.1초 카운트 애니메이션, 증감률 소수점 표시
- 비교 막대 순차 펼침, 레이더 파동과 반짝임, 버튼 광택·북마크 팝 효과
- 타임라인 등장, 모달 스프링, 저장 완료 링·파티클 피드백
- OS의 `prefers-reduced-motion` 설정 시 숫자를 즉시 표시하고 장식 애니메이션을 비활성화
- 스크린 리더는 중간 카운트 대신 최종 수치만 읽으며, 미완료 프레임은 화면 해제 시 정리

기존 색상·화면 배치와 기능을 유지했습니다. `AnimatedNumber.tsx` 모션 검사를 추가하여 총 19개 테스트를 통과했습니다. 실제 브라우저 시각 검증은 Windows 원격 조작 없이 진행하지 않았습니다.
