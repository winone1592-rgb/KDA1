## 디자인

- [화면 목록 및 미리보기](design/README.md)
- [원본 PNG](design/screens/)
- [구현 작업 지침](AGENTS.md)

현재 디자인 자료는 PNG 14개입니다. Figma 원본(.fig)과 Figma 파일 URL은 제공되지 않았으며, 현재 PNG 기반 앱 코드가 포함되어 있습니다. PNG는 시각 참조이며 편집 가능한 Figma 레이어나 컴포넌트 정보는 제공하지 않습니다.

위 요청은 확장 작업의 예시입니다. 현재 구현은 설치가 필요 없는 HTML/CSS/JavaScript입니다. GitHub에 저장된 파일은 다음 구현 작업의 기준으로 사용할 수 있습니다.

## 구현된 앱 실행

Node.js 20 이상에서 추가 패키지 설치 없이 실행할 수 있습니다.

```sh
node server.mjs
```

브라우저에서 http://localhost:5173 을 엽니다. `index.html`, `src/style.css`, `src/app.js`를 일반 정적 호스팅에 배포할 수도 있습니다.

### 구현 범위

- 변화 피드, 보고서 필터, 내 종목 필터
- 공시 상세 수치 비교 → AI 설명 및 근거 → 정정 이력 타임라인
- 종목 검색·추가·삭제, 관심종목 등록 온보딩
- 알림 내역 및 모두 읽기
- 푸시·긴급 알림·보고서 유형·종목별 설정과 저장 완료 피드백
- 화면 하단 ‘디자인 예외 상태 미리보기’에서 관심종목 없음, 새 변화 없음, 수집 실패·재시도, 비교문서 없음, AI 설명 보류 확인
- 관심종목, 알림 읽음 상태, 저장한 설정은 localStorage로 브라우저에 보관

### 디자인과 가정

원본 Figma 링크 또는 .fig가 없어 제공된 PNG 14개를 기준으로 HTML/CSS 컴포넌트를 구현했습니다. 화면 전체 이미지를 배경으로 사용하지 않습니다. 아이콘은 별도 벡터 자산이 제공되지 않아 문자 기호로 근사했으며 폰트·세부 치수도 PNG를 기준으로 조정했습니다. 화면 이동, 필터 규칙, 저장 방식과 일부 상세 문구는 구현을 위한 가정입니다. React 의존성 없이 브라우저 표준 모듈을 사용합니다.

기업·공시·AI 설명은 가상 데이터입니다. DART 링크는 실제 특정 접수 원문 대신 DART 홈페이지를 엽니다. 실시간 수집, AI API, OS 푸시 및 서버 저장은 구현하지 않았습니다.
