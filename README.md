# KDA1 · KIWOOM RADAR

공시 변화 탐지 모바일 UI를 구현하기 위한 디자인 참조 저장소입니다.

## 디자인

- [화면 목록 및 미리보기](design/README.md)
- [원본 PNG](design/screens/)
- [구현 작업 지침](AGENTS.md)

현재 디자인 자료는 PNG 14개입니다. Figma 원본(.fig), Figma 파일 URL, 코드 및 실행 환경은 아직 포함되어 있지 않습니다. PNG는 시각 참조이며 편집 가능한 Figma 레이어나 컴포넌트 정보는 제공하지 않습니다.

이 저장소를 코딩 에이전트에서 열고 다음과 같이 요청하세요.
